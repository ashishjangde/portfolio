## Installed Agent Skills

The following skills are installed in `.agents/skills/` and available for agent workflows:

- **`shadcn`** (`.agents/skills/shadcn`): Guidance for adding, styling, configuring, and composing shadcn UI components with Tailwind CSS v4.
- **`find-skills`** (`.agents/skills/find-skills`): Helper to search and install additional agent skills from the open agent skills ecosystem (`npx skills`).
